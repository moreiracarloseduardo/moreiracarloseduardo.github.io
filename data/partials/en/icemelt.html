Technical Analysis: IceMeltRace

IceMeltRace features a real-time ice melting system combining advanced Unity tech for an immersive mechanic, demonstrating shader programming, real-time rendering, physics, and optimization expertise.

Key Achievement: Fully dynamic ice interaction with flamethrower heat mapping, maintaining 60+ FPS while converting ice to water resources.

Heatmap Shader

Material Properties: Heatmap RenderTexture input, Fresnel edges, normal mapping, transparency control, refraction.

Innovation: Flamethrower particles paint heat values into a render texture read by the shader for realistic melting.

Modular Grid Architecture

// Procedural Ice Block Generation
for (int i = 0; i < widthObject; i++) {

        Vector3 position = CalculateGridPosition(i, j);

        ConfigurePhysicsAndNavigation(iceBlock);
    }
}

Scalability: Auto-generates grids of any size; each block is independently meltable and auto-regenerates after 10 seconds.

// Cascading Scale Animation
void Animate() {
    for (int i = 0; i < cableSegments.Length; i++) {
        LeanTween.scale(cableSegments[i].transform.GetChild(0).gameObject, 
                       Vector3.one * 1.3f, 0.3f)
                .setFrom(Vector3.one * 0.9f)
                .setEaseOutSine()
                .setLoopPingPong()
                .setDelay(i * 0.05f);
    }
}

Impact: Wave-like animations along the cable; clear resource flow feedback.

Cable System Architecture

Segmented Physics Chain: 20+ segments (Rigidbody + CapsuleCollider), ConfigurableJoint links, material variation, proper layers.

public void ConnectCable(bool startSegment, Transform newTransform) {
    AwakeRigidbodies();
    int id = startSegment ? 0 : cableSegments.Length - 1;
    cableSegments[id].GetComponent<Rigidbody>().isKinematic = true;
    cableSegments[id].transform.parent = newTransform;
    LeanTween.moveLocal(cableSegments[id].gameObject, Vector3.zero, 0.2f);
    LeanTween.rotateLocal(cableSegments[id].gameObject, Vector3.zero, 0.2f);
}

Resource Transfer Visualization: Bidirectional animation (fuel forward, water backward), particle jets, 3D audio feedback, and smart disconnection by resource level.
