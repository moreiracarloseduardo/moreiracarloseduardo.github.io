Technical Analysis: CandyWorld - Idle Management Game

CandyWorld is an idle/management mobile game project built in Unity 3D, focusing on an automated production chain and non-linear progression. It served as an in-depth study of software architectures, design patterns, and mobile performance optimizations.

Architecture and Design Patterns

We used the State Machine Pattern to manage entity behavior (Idle → Find → Move → Buy → Leave), enabling controlled transitions and simpler debugging. The Singleton Pattern centralized managers (Audio, UI, Particles), and a Component-Based Architecture modularized buildings, characters, and objects.

Implemented Technical Systems

Behavioral AI System: NPCs with autonomous decision-making using Unity NavMesh (natural, efficient pathfinding). Includes patience and satisfaction systems.

}

Autonomous Helper AI System: Helpers optimize production with dynamic task prioritization based on the game state.

void Find_Enter() {
    Vector3 target = Vector3.zero;
    if (productsHolder.childCount > 0) {
        targetShelf = FindShelf();
    } else {
        targetMachine = FindMachineWithMoreProducts();
        if (targetMachine != null) {
            target = targetMachine.outShelf.transform.position;
        }
    }
    
    if (target != Vector3.zero) {
        NavMesh.SamplePosition(target, out NavMeshHit hit, 20, NavMesh.AllAreas);
        agent.SetDestination(hit.position);
    }
}

Automated Production System: End-to-end production from plants/ingredients to machines and sales. Coroutines manage async processes; a supply/demand balancer keeps economy dynamic.

IEnumerator Factory() {
    yield return new WaitForSeconds(1);
    if (inShelf.GetLastCollectable() != null) {
        Ingredient_ ingredient = inShelf.GetLastCollectable() as Ingredient_;
        IngredientType ingredientType = ingredient.type;
        
        for (int i = 0; i < productsPerIngredient; i++) {
            LeanTween.moveLocalY(piston, 0, .2f).setEase(LeanTweenType.easeInCubic).setLoopPingPong(1);
            yield return new WaitForSeconds(.05f);
            
            Product_ currentProduct = Instantiate(product, productStartPoint.position, transform.rotation);
            currentProduct.flavor = ingredientType;
            currentProduct.setFlavorMaterial();
            
            LeanTween.value(gameObject, 0, 1, Game_.instance.upgrades.machineSpeedValue).setOnUpdate((float val) => {
                conveyourRenderer.material.mainTextureOffset = new Vector2(0, -val * 2);
            });
            
            yield return new WaitForSeconds(Game_.instance.upgrades.machineSpeedValue);
            outShelf.SpawnCollectable(currentProduct);
        }
    }
    StartCoroutine(Factory());
}

Dynamic Progression System

Progression balanced with AnimationCurve and math formulas for upgrades, enabling rewarding content unlocking.

public int holdItensValue {
    get {
        return (int)Game_.instance.priceManager.holdItens.Evaluate((float)holdItensLevel / (maxLevel - 1));
    }
}

public float machineSpeedValue {
    get {
        return Game_.instance.priceManager.machineSpeed.Evaluate((float)machineSpeedLevel / (maxLevel - 1));
    }
}

Data Management System

Persistent Save/Load System: Automatic serialization with debounce, async/await for non-blocking operations.

Contextual Tutorial: Step-by-step tutorial with action validation, persisted via PlayerPrefs; non-intrusive, dynamic UI.

Optimizations and Performance

Object Pooling: Reduced GC for particles/objects.

Tweening System: Smooth visuals without framerate impact.

Modular Loading: Lazy activation/deactivation via building manager.

Results and Technical Metrics

Stable 60 FPS on mid-range devices; memory footprint under 200MB. Highly scalable architecture with excellent maintainability. Demonstrates architecture, mobile optimization, AI implementation, complex systems design, and SDK integration.
