Technical Analysis: IdleTrain - Incremental Railway Management System

IdleTrain is a sophisticated idle/incremental mobile game focused on railway management, passenger transportation, and exponential progression mechanics. It demonstrates advanced systems implementation, mathematical balancing, and mobile performance optimization while keeping engaging idle gameplay.

Architecture and Design Patterns

State Machine Pattern for core flow (Start → Game → End); Singleton for Game_ providing a unified access point to Audio_, Particle_, UI_, Camera_, and SaveSystem_; Component-Based Architecture with Train_, Wagon_, Passenger_, Station_ as modular components.

Procedural Movement and Pathfinding

Bézier curves via LTBezierPath for smooth, natural movement along complex tracks.

Implements: Ratio-based positioning (0-1), dynamic path recalculation at forks, real-time interpolation.

Intelligent Merge and Upgrade System

3-to-1 merge with auto-detection and level progression.

public bool CanMerge() {
    for (int i = 0; i <= maxLevel; i++) {
        for (int j = 0; j < wagons.Count; j++) {
            if (wagons[j].Level == i && wagonsToMerge.Count < 3) wagonsToMerge.Add(wagons[j]);
        }
    }
    return wagonsToMerge.Count == 3;
}

Dynamic Economy and Progression

Quadratic pricing with track multiplier; real-time money-per-second sampling; track-based difficulty scaling; exponential passenger value.

public ulong PriceFormula(float A, float B, float C, int level, int trackMultiplier) {
    level = level + (trackMultiplier * Game_.instance.data.track);
    return (ulong)(A * Mathf.Pow(level, 2) + (B * level) + C);
}
