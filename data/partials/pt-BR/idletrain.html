Análise Técnica: IdleTrain - Sistema Incremental Ferroviário

IdleTrain é um jogo mobile incremental focado em gestão ferroviária, transporte de passageiros e progressão exponencial. Demonstra implementação avançada de sistemas, balanceamento matemático e otimizações para mobile mantendo gameplay idle envolvente.

Arquitetura e Padrões

State Machine para o fluxo (Start → Game → End); Singleton para Game_ (ponto único de acesso a Audio_, Particle_, UI_, Camera_, SaveSystem_); Arquitetura por Componentes (Train_, Wagon_, Passenger_, Station_).

Movimento Procedural e Pathfinding

Curvas Bézier via LTBezierPath para movimento natural em trilhos complexos.

Merge 3→1 e Upgrades

Algoritmo de merge com detecção automática e progressão de nível.

public bool CanMerge() {
    for (int i = 0; i <= maxLevel; i++) {
        for (int j = 0; j < wagons.Count; j++) {
            if (wagons[j].Level == i && wagonsToMerge.Count < 3) wagonsToMerge.Add(wagons[j]);
        }
    }
    return wagonsToMerge.Count == 3;
}

Economia e Progressão

Preço quadrático com multiplicador de trilhos; cálculo de money-per-second; dificuldade por trilho; valor de passageiro exponencial.

public ulong PriceFormula(float A, float B, float C, int level, int trackMultiplier) {
    level = level + (trackMultiplier * Game_.instance.data.track);
    return (ulong)(A * Mathf.Pow(level, 2) + (B * level) + C);
}

Otimizações e Performance

Object Pooling; operações assíncronas via Coroutines; cache de componentes; transições de câmera dinâmicas.

Desafios Técnicos Resolvidos

Balanceamento exponencial de progressão; posicionamento multi-objeto em Bézier; gestão de memória; consistência de dados cross-platform; algoritmos eficientes de money-per-second.

Métricas Técnicas e Resultados

60 FPS em devices mid-tier; memória < 180MB; carregamento < 3s; zero memory leaks em longas sessões; saves < 100ms. Arquitetura escalável, de fácil manutenção e robusta.
