Análise Técnica: WaterPuzzle

WaterPuzzle é um jogo de quebra-cabeça mobile desenvolvido em Godot 4, onde os jogadores devem organizar líquidos coloridos despejando-os entre latas até que cada recipiente contenha apenas uma cor pura. O projeto demonstra programação avançada de shaders, simulação de física de mola e geração procedural de quebra-cabeças sem depender de motores de física 3D pesados.

Este projeto demonstra maestria em programação de shaders GLSL, simulação física, geração procedural e otimização de desempenho para plataformas mobile. Todo o comportamento do líquido—desde ondas de superfície até inércia—é alcançado através de shaders personalizados e física de mola, resultando em visuais realistas com custo mínimo de desempenho.

O Desafio: Líquido Realista Sem Física 3D

Simular comportamento realista de líquidos é computacionalmente caro. Abordagens tradicionais usando sistemas de partículas ou dinâmica de fluidos são proibitivas para dispositivos móveis. O desafio era criar física de líquidos convincente—incluindo tensão superficial, propagação de ondas, inércia e camadas multicoloridas—usando apenas shaders 2D e modelos matemáticos.

Além disso, o jogo precisava suportar níveis dinâmicos de dificuldade com capacidades variadas de latas (3-8 unidades), múltiplas cores de líquido com propriedades visuais distintas, animações suaves de despejo com temporização realista e manter 60 FPS em dispositivos móveis de médio alcance.

Solução 1: Shader de Líquido Multi-Camadas

A inovação central é um shader GLSL personalizado (liquid_lab.gdshader) que renderiza até 8 camadas distintas de líquido com cores individuais, comportamento realista de superfície e efeitos visuais avançados. O shader opera inteiramente no espaço UV, transformando coordenadas baseadas no ângulo de inclinação da lata para simular gravidade.

Recursos Principais do Shader:

  • Transformação UV Baseada em Gravidade: Usa uma matriz de rotação para alinhar a superfície do líquido com o vetor gravitacional, mantendo o líquido sempre "nivelado" independentemente da orientação da lata.
  • Sistema Multi-Camadas: Suporta até 8 camadas de cor com mistura suave entre limites. Cada camada tem quantidades configuráveis de mistura para transições verticais e horizontais.
  • Efeito Menisco: Simula curvatura de superfície perto das paredes da lata usando pow(abs(x_offset), 3.0) para formas côncavas/convexas fisicamente precisas.
  • Propagação de Ondas: Geração de ondas baseada em seno com frequência e amplitude configuráveis, sincronizadas com o tempo do jogo.
  • Simulação de Agitação: Oscilação horizontal usando ondas senoidais com mudança de fase para simular momentum do líquido durante animações de despejo.
  • Iluminação de Borda: Detecção de bordas usando gradientes alfa de máscara para criar realces realistas nos limites do líquido.
// Transformação de gravidade central em liquid_lab.gdshader
mat2 rotation_matrix(float angle) {
    float cos_a = cos(angle);
    float sin_a = sin(angle);
    return mat2(vec2(cos_a, sin_a), vec2(-sin_a, cos_a));
}

void fragment() {
    // Transforma coordenadas UV baseado na inclinação da lata
    vec2 center_uv = UV - vec2(0.5);
    vec2 gravity_uv = rotation_matrix(tilt_angle) * center_uv + vec2(0.5);
    
    // Calcula posição da superfície com múltiplos efeitos
    float surface = base_surface + inertia_shift + slope_offset + meniscus + wave + slosh;
    
    // Determina se o pixel está acima ou abaixo da superfície do líquido
    float liquid_factor = smoothstep(
        surface - surface_smoothing, 
        surface + surface_smoothing, 
        gravity_uv.y
    );
    
    // Amostra cor correta da camada baseado na profundidade
    vec4 final_color = sample_layer_color(depth_ratio_flat, depth_ratio_slope, gravity_uv);
    
    // Aplica iluminação de borda nas extremidades
    final_color.rgb = mix(
        final_color.rgb * (1.0 + rim_light_boost), 
        final_color.rgb, 
        edge_lerp
    );
    
    COLOR = final_color;
}

Solução 2: Física de Mola para Inércia de Líquido

Para complementar o shader, implementei um sistema de mola-amortecedor em GDScript que simula inércia do líquido e oscilação de superfície. Isso cria um "atraso" de aparência natural quando a lata gira, fazendo o líquido parecer ter massa e momentum.

Componentes da Física:

  • Física do Ângulo de Superfície: Sistema de mola com rigidez configurável (18.0) e amortecimento (7.5) que faz a superfície do líquido gradualmente se alinhar com a gravidade.
  • Deslocamento de Superfície: Deslocamento lateral baseado em velocidade angular, simulando líquido "agitando" para um lado durante rotação.
  • Amortecimento Adaptativo: Maior amortecimento quando vertical (0.88) para reduzir oscilação em repouso, menor quando inclinado (0.94) para movimento mais dinâmico.
  • Perfis Por Líquido: Diferentes multiplicadores de onda, menisco e realce para cada tipo de cor (ex: água é mais ondulada, xarope tem menisco mais forte).
# Sistema de física de mola em can.gd
func _advance_surface_physics(delta: float, current_rotation: float) -> void:
    # Calcula ângulo alvo (direção da gravidade)
    var target_angle = -current_rotation if surface_angle_mode == SurfaceAngleMode.NATURAL else 0.0
    
    # Modelo mola-amortecedor para ângulo de superfície
    var angle_error = target_angle - _surface_angle
    var angle_force = angle_error * surface_angle_stiffness
    _surface_angle_velocity += angle_force * delta
    _surface_angle_velocity -= _surface_angle_velocity * surface_angle_damping * delta
    _surface_angle += _surface_angle_velocity * delta
    
    # Calcula deslocamento lateral da rotação e velocidade
    var angular_velocity = (current_rotation - _previous_rotation) / delta
    var target_offset = current_rotation * surface_offset_from_angle
    target_offset += angular_velocity * surface_offset_from_speed
    
    # Aplica amortecimento adaptativo baseado na verticalidade
    var damping = lerp(vertical_damp, tilted_damp, abs(sin(current_rotation)))

Solução 3: Sistema de Animação de Despejo Otimizado

A animação de despejo orquestra múltiplos sistemas em uma sequência de 3 fases: Levantar & Inclinar (0.28s), Despejar (0.4-1.2s variável) e Retornar (0.32s). Crucialmente, as fases se sobrepõem em 0.12s para eliminar pausas visíveis e criar um ciclo de animação 28% mais rápido.

Destaques Técnicos:

  • Curvas Bezier: Funções de easing personalizadas usando curvas de Bézier cúbicas para aceleração/desaceleração natural durante fases de levantamento e retorno.
  • Máquina de Estados: Rastreamento robusto de estado de animação (IDLE → ANIMATING → COMMITTING) com temporização perfeita por frame usando _process(delta).
  • Lógica de Transferência de Líquido: Validação em tempo real garantindo sem enchimento excessivo, ordem adequada de empilhamento de cores e commit/rollback atômico na conclusão da animação.
  • Desempenho: Zero pressão GC—todos os cálculos usam tipos primitivos, sem objetos intermediários ou alocações de string durante animação.

Resultados & Impacto

Métricas de Desempenho:

  • 60 FPS sustentados em dispositivos móveis de médio alcance (testado em telefones Android de 2019)
  • ≤2ms de tempo de frame para renderização de shader com 8 camadas de líquido
  • Zero alocações de heap durante o jogo (sem engasgos de GC)
  • 28% animações mais rápidas através de otimização de sobreposição de fases

Conquistas Técnicas:

  • Desenvolveu shader GLSL personalizado com sistema de cor de 8 camadas, simulação de gravidade, efeito menisco e propagação de ondas
  • Implementou física de mola-amortecedor para inércia realista de líquido sem motor de física 3D
  • Criou gerador procedural de quebra-cabeças com algoritmo de resolução reversa garantindo solubilidade
  • Arquitetou máquina de estados de animação com temporização perfeita por frame e transferências atômicas de líquido
  • Otimizado para mobile: 60 FPS, ≤2ms de tempo de shader, zero pressão GC

Aprendizados Principais:

Este projeto reforçou o poder da programação de shaders para criar efeitos visuais complexos com custo mínimo de desempenho. A combinação de transformações no espaço UV, física de mola e gerenciamento cuidadoso de estado demonstra que comportamento realista de líquido não requer simulações 3D caras—apenas uma compreensão profunda da matemática subjacente.

O sistema de geração procedural se provou particularmente valioso, permitindo variações infinitas de quebra-cabeças enquanto garante solubilidade através de validação de resolução reversa. Esta abordagem é amplamente aplicável a qualquer jogo de quebra-cabeça que requer escalonamento dinâmico de dificuldade.
