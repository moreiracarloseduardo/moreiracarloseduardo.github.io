Análise Técnica: CandyWorld - Idle Management Game

CandyWorld é um projeto mobile idle/management desenvolvido em Unity 3D, com foco em cadeia de produção automatizada e progressão não-linear. Serviu como estudo aprofundado de arquiteturas de software, design patterns e otimizações de performance para mobile.

Arquitetura e Padrões de Projeto

Utilizamos State Machine Pattern para gerenciar comportamentos (Idle → Find → Move → Buy → Leave), facilitando depuração e previsibilidade. O Singleton centralizou managers (Audio, UI, Particles). A arquitetura baseada em componentes modularizou edifícios, personagens e objetos.

Sistemas Técnicos Implementados

AI de Clientes: NPCs autônomos com NavMesh (caminhamento natural/eficiente), paciência/satisfação para afetar a experiência.

}

AI de Helpers: Otimização de produção com priorização dinâmica de tarefas conforme o estado do jogo.

void Find_Enter() {
    Vector3 target = Vector3.zero;
    if (productsHolder.childCount > 0) {
        targetShelf = FindShelf();
    } else {
        targetMachine = FindMachineWithMoreProducts();
        if (targetMachine != null) {
            target = targetMachine.outShelf.transform.position;
        }
    }
    
    if (target != Vector3.zero) {
        NavMesh.SamplePosition(target, out NavMeshHit hit, 20, NavMesh.AllAreas);
        agent.SetDestination(hit.position);
    }
}

Pipeline de Produção: Do plantio e coleta à transformação em máquinas e venda. Coroutines para processos assíncronos e balanceamento oferta/demanda.

IEnumerator Factory() {
    yield return new WaitForSeconds(1);
    if (inShelf.GetLastCollectable() != null) {
        Ingredient_ ingredient = inShelf.GetLastCollectable() as Ingredient_;
        IngredientType ingredientType = ingredient.type;
        
        for (int i = 0; i < productsPerIngredient; i++) {
            LeanTween.moveLocalY(piston, 0, .2f).setEase(LeanTweenType.easeInCubic).setLoopPingPong(1);
            yield return new WaitForSeconds(.05f);
            
            Product_ currentProduct = Instantiate(product, productStartPoint.position, transform.rotation);
            currentProduct.flavor = ingredientType;
            currentProduct.setFlavorMaterial();
            
            LeanTween.value(gameObject, 0, 1, Game_.instance.upgrades.machineSpeedValue).setOnUpdate((float val) => {
                conveyourRenderer.material.mainTextureOffset = new Vector2(0, -val * 2);
            });
            
            yield return new WaitForSeconds(Game_.instance.upgrades.machineSpeedValue);
            outShelf.SpawnCollectable(currentProduct);
        }
    }
    StartCoroutine(Factory());
}

Progressão Dinâmica

Progressão balanceada com AnimationCurve e fórmulas matemáticas de upgrade, permitindo desbloqueios graduais e recompensadores.

public int holdItensValue {
    get {
        return (int)Game_.instance.priceManager.holdItens.Evaluate((float)holdItensLevel / (maxLevel - 1));
    }
}

public float machineSpeedValue {
    get {
        return Game_.instance.priceManager.machineSpeed.Evaluate((float)machineSpeedLevel / (maxLevel - 1));
    }
}

Gestão de Dados

Save/Load Persistente: Serialização automática com debounce e async/await para operações não bloqueantes. Tutorial Contextual: passo a passo validando ações, persistido via PlayerPrefs, UI dinâmica e não-invasiva.

Otimizações e Performance

Object Pooling: Redução de GC em partículas/objetos.

Sistema de Tween: Feedback visual fluido sem impactar FPS.

Carregamento Modular: Ativação/desativação lazy via gerenciador de prédios.

Resultados e Métricas

60 FPS em devices mid-range; memória < 200MB. Arquitetura escalável e de alta manutenção. Demonstra arquitetura, otimização mobile, AI, design de sistemas e integração com SDKs.
